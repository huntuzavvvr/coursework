# Сборка, сквозные проверки, оформление

> Историческая запись первой версии. После упрощения актуальны [README](../README.md) и [этап 04](04-simplification.md).

17 сентября 2026, OpenAI Codex. Локальная среда: macOS arm64,
.NET SDK 10.0.100, Python из системного окружения. SDK был загружен из
официального дистрибутива Microsoft и помещён в игнорируемую `.tools/`.

Команда проверки из `mosaic/`:

```sh
./scripts/verify.sh
```

Получено: Release-сборка без предупреждений и ошибок; **73/73** F#-теста;
прошли независимые сквозные проверки всех **12** примеров, JSON, REPL,
диагностик, бюджетов и файлового ввода-вывода. Проверено, что неоднозначный
вывод не заменяет существующий файл, и что отсутствие артефакта хотя бы в
одном мире также запрещает экспорт.

При сборке CLI понадобилась явная аннотация string для выбора перегрузки
Int32.TryParse. Параллельная MSBuild-сборка в ограниченном окружении зависала;
скрипты используют `-m:1 -nodeReuse:false`. Последовательная сборка решения
и весь тестовый прогон успешно завершились.

Подготовлены README, руководство, грамматика, семантика, API/CLI,
разборы примеров, матрица требований, вопросы к защите и конфигурация Pages.
Pages не объявляется опубликованным. Пользователь подтвердил индивидуальное выполнение; ФИО не предоставлено.

GitHub CI настроен на Ubuntu и macOS. Факт удалённого прохождения CI
проверяется отдельно по GitHub Actions; локальный прогон не подменяет его.
