# Проверка первой версии

Историческая запись. 17 сентября 2026, OpenAI Codex.

Локальная среда: macOS arm64, .NET SDK 10.0.100 и Python. SDK был загружен
из официального дистрибутива Microsoft в игнорируемую папку `.tools/`.

Первая версия прошла Release-сборку без ошибок и предупреждений, 73 теста
и проверки 12 примеров. В ней ещё были дополнительные режимы CLI, удалённые
при последующем упрощении. Эти числа не описывают текущую версию.

Параллельная MSBuild-сборка в ограниченном окружении зависала; для локальной
проверки использован режим `-m:1 -nodeReuse:false`. Он сохранён в скриптах.

Подготовлены документация и конфигурации GitHub Actions и Pages. Публикация
Pages не выполнялась. Результат локальной проверки не является подтверждением
прохождения удалённого CI.
