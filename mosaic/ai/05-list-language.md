# Переход к обработке списков

17 сентября 2026. Изменения подготовлены с помощью OpenAI Codex по запросу
автора о более простом языке для индивидуального курсового проекта.

- Вычисление программы теперь даёт одно обычное значение.
- Оставлен один числовой тип: целые числа bigint; деление целочисленное.
- Добавлена форма pipe для последовательного применения функций.
- Библиотека map/filter/foldl и ленивые потоки сохранены на самом Mosaic.
- Добавлены примеры цепочки преобразований и обработки оценок.
- Упрощены CLI и структуры результата, обновлена документация.

Проверка: Release-сборка без ошибок и предупреждений, 70 тестов на F#,
семь примеров и сквозные проверки CLI. Отдельно проверяются порядок шагов pipe,
частичное применение, замыкания и сохранение файлов при ошибке вычисления.
