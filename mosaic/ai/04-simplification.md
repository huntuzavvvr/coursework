# Упрощение учебного проекта

По просьбе автора работа приближена по масштабу и структуре к предоставленному
примеру. Изменения выполнены с помощью OpenAI Codex.

- Вместо CEK-машины введён обычный рекурсивный интерпретатор.
- Удалены JSON, REPL, отдельный режим check и настраиваемые бюджеты машины.
- Для учебных программ оставлены простые пределы глубины и числа сценариев.
- Сохранены функции, рекурсия, замыкания, списки, явная ленивость и файловый I/O.
- Основная особенность остаётся одной: именованные вероятностные выборы с observe.
- Набор демонстраций сокращён с 12 до 7. Неподдерживаемые теперь тесты глубокой
  стекобезопасной рекурсии удалены; проверяются новые ограничения интерпретатора.
- Документация организована как README, syntax, api, examples, architecture и
  краткий PROJECT_STATUS, без повторения длинной спецификации.

Проверено: Release-сборка без предупреждений и ошибок; 71/71 тест на F#;
все 7 примеров, диагностики CLI и файловый ввод-вывод. Основной код содержит
617 строк F# против 513 строк в предоставленном примере (тесты в эти числа
не входят). Число строк служит ориентиром масштаба, а не мерой сложности.
