## Идея

В Mosaic задача разбивается на небольшие функции. Их можно вызывать отдельно
или объединять в цепочку через `pipe`: каждый шаг получает результат
предыдущего. Например, сумма квадратов чётных чисел:

```lisp
(pipe (range 1 11)
  (filter (fn [x] (= (mod x 2) 0)))
  (map (fn [x] (* x x)))
  sum)
```

Результат: `220`. Сначала строится список от 1 до 10, затем остаются чётные
числа, вычисляются их квадраты и сумма. `map`, `filter` и `sum` написаны
на самом Mosaic. Цепочки преобразований — известный приём функционального
программирования; здесь он выбран как основа небольшого учебного языка.

## Возможности

- Целые числа произвольной точности, строки, логические значения и списки.
- Неизменяемые привязки `let` и условное выражение `if`.
- Функции `fn`, замыкания и частичное применение.
- Рекурсивные и взаимно рекурсивные функции через `letrec`.
- Последовательное применение функций через `pipe`.
- Отложенные вычисления `delay` / `force` и ленивые потоки.
- Стандартная библиотека обработки списков.
- Чтение и запись текстовых файлов через CLI.
- Ошибки с указанием строки и столбца.

## Установка и запуск

Требуется .NET SDK 10. Команды выполняются из папки `mosaic/`:

```sh
dotnet build Mosaic.slnx -c Release -m:1 -nodeReuse:false
./mosaic examples/factorial.mos
./mosaic examples/pipeline.mos
```

Скрипт `mosaic` собирает CLI перед запуском. Первый пример печатает
`2432902008176640000`, второй — `220`. На Windows можно запустить CLI напрямую:

```sh
dotnet run --project src/Mosaic.Cli -c Release -- examples/pipeline.mos
```

## Основы языка

Вызов записывается в круглых скобках: сначала функция, затем аргументы.
Списки заключаются в квадратные скобки. Комментарий начинается с `;`.
Файл содержит одно выражение, результат которого печатается после вычисления.

```lisp
(let [x 10
      double (fn [n] (* n 2))]
  (double (+ x 1)))
```

Результат: `22`. Привязки внутри `let` обрабатываются по порядку.

Рекурсивная функция задаётся через `letrec`:

```lisp
(letrec [fact (fn [n]
               (if (= n 0) 1 (* n (fact (- n 1)))))]
  (fact 6))
```

Результат: `720`. Из двух ветвей `if` вычисляется только выбранная.

Функции можно передавать как значения. Если аргументов меньше, чем параметров,
получается новая функция, ожидающая оставшиеся аргументы:

```lisp
(let [add-ten (+ 10)]
  (map add-ten [1 2 3]))
```

Результат: `[11 12 13]`. Поэтому `(map add-ten)` можно использовать как шаг
`pipe`: список будет передан ему следующим аргументом.

Все числа целые: `(/ 7 3)` равно `2`, `(/ -7 3)` равно `-2`.
Подробные правила — в [описании синтаксиса](docs/syntax.md).

## Файловый ввод-вывод

```sh
mkdir -p out
./mosaic examples/files.mos \
  --input message examples/message.txt \
  --output report out/report.txt
```

Программа обращается к именам `message` и `report`, пути задаются при запуске.
CLI читает входные файлы и передаёт их содержимое интерпретатору. Ядро возвращает
результат и таблицу подготовленных текстов; CLI записывает запрошенные выходы
после успешного вычисления. Один выход нельзя определить двумя разными текстами.

## Структура проекта

```text
src/Mosaic.Core/
  Syntax.fs       дерево выражений и позиции в тексте
  Reader.fs       чтение и разбор программы
  Values.fs       значения и замыкания
  Primitives.fs   встроенные операции
  Interpreter.fs  рекурсивное вычисление выражений
  Prelude.fs      стандартная библиотека на Mosaic
  Engine.fs       запуск и подготовка результата
src/Mosaic.Cli/   аргументы командной строки и файлы
tests/           проверки языка
examples/        программы на Mosaic
docs/            документация
ai/              записи этапов разработки
```

Ядро использует неизменяемые `Map` и списки. Рекурсивные замыкания хранят
описания функций, без `ref`. Устройство вычислителя разобрано в
[архитектуре](docs/architecture.md).

## Тестирование и ограничения

```sh
./scripts/verify.sh
```

Скрипт собирает проект, запускает 70 тестов на F# и проверяет все семь примеров,
обработку ошибок CLI и файловый ввод-вывод. Для сквозных проверок нужен
Python 3.10+. Тесты F# отдельно:

```sh
dotnet run --project tests/Mosaic.Tests -c Release
```

Интерпретатор учебный: статического вывода типов и оптимизации хвостовых вызовов
нет. Вложенность исходного текста и вычисления ограничена 256 уровнями.
Большие списки могут исчерпать глубину рекурсии. `delay` не кеширует результат.
Дробных чисел, модулей, компилятора и REPL нет.
