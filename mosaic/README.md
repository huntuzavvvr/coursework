# Mosaic — функциональный язык программирования

Mosaic — небольшой функциональный язык на F#. Он поддерживает функции,
рекурсию, замыкания и списки. Особенность языка — именованные выборы:
программа может вернуть несколько возможных результатов с точными вероятностями.

## Обзор

Основа языка — лямбда-выражения и применение функций. Значения неизменяемы,
область видимости лексическая, типизация динамическая. По умолчанию выражения
вычисляются строго; для отложенных вычислений есть `delay` и `force`.

Вызов `choose` описывает событие. Повторное обращение к тому же имени события
в одном сценарии возвращает прежний выбор:

```lisp
(let [weather (fn [ignored]
                 (choose "weather" [[3 "sun"] [1 "rain"]]))]
  [(weather 0) (weather 0)])
```

Результат:

```text
["rain" "rain"] @ 1/4
["sun" "sun"] @ 3/4
evidence = 1; worlds = 2
```

Смешанных пар здесь нет: оба вызова спрашивают об одной погоде.
Разные имена событий дают независимые выборы. `observe` позволяет оставить
только сценарии, удовлетворяющие условию.

## Синтаксис языка

Вызов записывается как `(функция аргументы)`, список — как `[элементы]`.
Файл содержит одно выражение, комментарии начинаются с `;`.

```lisp
(let [double (fn [x] (* x 2))
      numbers [1 2 3 4]]
  (map double numbers))
```

Результат: `[2 4 6 8] @ 1`.

Факториал:

```lisp
(letrec [fact (fn [n]
               (if (= n 0) 1 (* n (fact (- n 1)))))]
  (fact 6))
```

Результат: `720 @ 1`. Полное описание — в [синтаксисе](docs/syntax.md).

## Стандартная библиотека

| Группа | Функции |
|---|---|
| Арифметика | `+`, `-`, `*`, `/`, `mod` |
| Сравнения | `=`, `<`, `<=`, `>`, `>=`, `not` |
| Списки | `cons`, `head`, `tail`, `empty?`, `length`, `append` |
| Высший порядок | `map`, `filter`, `foldl`, `compose`, `identity` |
| Обработка списков | `range`, `take`, `reverse`, `sum`, `product`, `all`, `any`, `zip` |
| Потоки | `iterate`, `stream-take` |
| Текст и файлы | `text-append`, `show`, `read-text`, `write-text` |
| Выбор | `choose` |

`if`, `let`, `letrec`, `fn`, `delay`, `force` и `observe` — специальные
формы, а не библиотечные функции. Подробности и примеры — в [API](docs/api.md).

## Сборка и запуск

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0), в который
входит F#. Дополнительных библиотек, кроме FSharp.Core из SDK, нет.
Команды ниже выполняются из папки `mosaic/`.

```sh
dotnet build Mosaic.slnx -c Release -m:1
dotnet run --project src/Mosaic.Cli -c Release -- examples/factorial.mos
```

На macOS и Linux можно использовать короткую команду:

```sh
./mosaic examples/factorial.mos
./mosaic examples/shared-weather.mos --explain
./mosaic examples/dice.mos
```

Скрипт сам собирает программу и выбирает системный .NET или локальный SDK
из `.tools/dotnet/`. Локальный SDK и результаты сборки не хранятся в Git.

Файловый ввод-вывод:

```sh
mkdir -p out
./mosaic examples/files.mos \
  --input message examples/message.txt \
  --output report out/report.txt
```

Программа оперирует именами `message` и `report`; пути задаются при запуске.
Если сценарии предлагают разные тексты для одного выхода, файл не записывается.

## Архитектура проекта

```text
src/Mosaic.Core/
  Syntax.fs       AST, позиции в тексте и точные числа
  Reader.fs       чтение выражений и проверка синтаксиса
  Values.fs       значения, замыкания, окружения и сценарии
  Interpreter.fs  рекурсивное вычисление AST
  Primitives.fs   встроенные операции
  Prelude.fs      библиотечные функции на Mosaic
  Engine.fs       запуск и объединение результатов
src/Mosaic.Cli/   работа с аргументами и файлами
tests/           проверки языка
examples/        примеры программ
docs/            документация
```

Интерпретатор использует обычное сопоставление с образцом по узлам AST.
Окружение — неизменяемый `Map`. Рекурсивные замыкания хранят описание функций,
поэтому не требуют `ref`. Чтение и запись файлов вынесены в CLI.
Подробнее — в [архитектуре](docs/architecture.md).

## Тестирование и ограничения

```sh
./scripts/verify.sh
```

Проверка запускает сборку, 71 тест на F# и все семь примеров. Для сквозных
проверок CLI нужен Python 3.10+. Тесты F# отдельно запускаются через
`dotnet run --project tests/Mosaic.Tests -c Release`.

Это учебный интерпретатор: оптимизации хвостовых вызовов нет. Глубина
вложенного вычисления ограничена 256 уровнями, размер промежуточного списка
сценариев — 1024. Ленивые выражения не кешируются. Полный перебор вариантов
может быть дорогим. Статического вывода типов, компилятора и IDE нет.
