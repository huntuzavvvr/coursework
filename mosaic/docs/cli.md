# Командная строка и API

## Команды

```sh
./mosaic run examples/dice.mos --explain
./mosaic eval '(+ (/ 1 3) (/ 1 6))'
./mosaic check examples/dice.mos
./mosaic repl
./mosaic --version
```

`check` проверяет синтаксис одного выражения: типы, имена, завершение и
согласованность событий требуют исполнения. REPL читает одно выражение на
строку. Каждая строка имеет новое окружение и новый набор миров; постоянных
привязок между строками нет. `:quit` завершает сеанс.

| Опция run/eval | Назначение |
|---|---|
| `--explain` | исходные и нормированные веса, значения именованных решений |
| `--json` | JSON, включая объяснения и логические артефакты |
| `--input NAME PATH` | прочитать UTF-8 файл перед интерпретацией |
| `--output NAME PATH` | записать согласованный артефакт после интерпретации |
| `--max-steps N` | положительный общий бюджет переходов; по умолчанию 2 000 000 |
| `--max-worlds N` | положительный бюджет сценариев; по умолчанию 10 000 |

Коды завершения: **0** — успех, **1** — ошибка источника, вычисления, файла
или экспорта, **2** — неправильные аргументы CLI. Диагностика идёт в stderr.
При превышении лимита частичного распределения не возвращается.

## Формат JSON

Для `./mosaic eval '42' --json`:

```json
{
  "evidence": "1",
  "outcomes": [{"value": "42", "probability": "1"}],
  "witnesses": [{
    "value": "42",
    "priorWeight": "1",
    "posteriorWeight": "1",
    "decisions": [],
    "outputs": []
  }]
}
```

Также возвращаются целочисленные `steps` и `worldsCreated`; их точные значения
зависят от реализации машины. Порядок полей JSON не является частью контракта.
`value` — строка с печатным представлением данных Mosaic, не вложенное
JSON-значение. Вероятности и evidence — строки с точными дробями, чтобы не
терять точность. Решение имеет поля `name` и `value`; артефакт — `name` и
`contents`.

## Встраивание в F#

Добавьте ссылку на проект `Mosaic.Core`:

```fsharp
open Mosaic

let result = Engine.run "(sum (range 1 11))"
// Result<Report, Diagnostic>

let context = { Inputs = Map.ofList ["message", "hello"] }
let configured =
    Engine.evaluate
        { MaxSteps = 100000; MaxWorlds = 100 }
        context
        "(write-text \"report\" (read-text \"message\"))"
```

`Engine.evaluate` не обращается к файловой системе и консоли.
`Reader.parse` возвращает `Result<Expr, Diagnostic>` без запуска.
`Engine.resolveOutput alias report` возвращает согласованный текст или
сообщение о расхождении миров; запись выполняет вызывающая программа.

## Основные диагностики

| Код | Причина |
|---|---|
| `E_EOF`, `E_DELIMITER`, `E_TRAILING` | незавершённое/несогласованное выражение или лишний код |
| `E_STRING`, `E_ESCAPE` | незакрытая строка или неподдерживаемый escape |
| `E_BINDING`, `E_FN`, `E_LETREC`, `E_FORM` | неправильная специальная форма |
| `E_DEPTH` | синтаксическая вложенность более 256 |
| `E_NAME` | неизвестное имя |
| `E_TYPE`, `E_CALL`, `E_FORCE`, `E_RESULT` | несовместимый тип значения |
| `E_ZERO`, `E_EMPTY` | деление на ноль или операция над пустым списком |
| `E_WEIGHT`, `E_CHOICE`, `E_KEY` | недопустимое или противоречивое распределение |
| `E_IMPOSSIBLE` | наблюдения исключили все миры |
| `E_INPUT`, `E_OUTPUT`, `E_EXPORT` | отсутствующий вход, конфликт артефакта или неоднозначный экспорт |
| `E_STEPS`, `E_WORLDS`, `E_LIMIT` | превышение/некорректность бюджета |
| `E_IO`, `E_USAGE` | ошибка ОС или аргументов CLI |

Позиции — строка и столбец с единицы. Пример: `<eval>:1:6: E_NAME: Unknown name 'x'`.
