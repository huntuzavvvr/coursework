# Вопросы к защите

[Документация](index.md)

1. **Почему язык функциональный?** Значения не изменяются, функции передаются
   как аргументы и возвращаются из других функций. Повторение выражается через
   рекурсию. В ядре используются неизменяемые окружения и списки.
2. **Для чего нужен pipe?** Он показывает обработку слева направо. Например,
   `(pipe xs (map f) sum)` сначала преобразует элементы, затем считает сумму.
   Шаги используют обычные функции и частичное применение.
3. **Как работает замыкание?** Функция хранит тело, параметры и окружение места
   определения. Вызов расширяет сохранённое окружение значениями аргументов.
4. **Как устроена рекурсия без изменяемых ссылок?** Рекурсивное замыкание хранит
   описания функций группы. При вызове из них создаётся окружение с теми же именами.
5. **Какие вычисления ленивые?** Только явно отложенные через `delay`; `force`
   вычисляет их каждый раз заново. Аргументы обычных функций вычисляются сразу.
6. **Где происходит файловый ввод-вывод?** В CLI. Интерпретатор получает тексты
   входов и возвращает тексты выходов как обычные данные.
7. **Почему синтаксис со скобками?** Его можно разобрать небольшим рекурсивным
   парсером без таблицы приоритетов операторов.
8. **Какие ограничения у реализации?** Целые числа без дробной части,
   динамическая проверка типов, ограничение глубины вычисления, отсутствие
   оптимизации хвостовой рекурсии и кеширования ленивых выражений.
9. **Что проверяют тесты?** Результаты программ, области видимости, порядок
   шагов цепочки, рекурсию, ленивость, диагностики и границу файлового вывода.

Для демонстрации можно запустить `factorial.mos`, `closures.mos`, `pipeline.mos`
и `streams.mos`, затем показать соответствующие ветви `eval` и библиотечный `map`.
