6. Поток Фибоначчи: зачем нужны delay и force.

## Что нужно понимать

- В `eval` каждому виду AST соответствует ветка сопоставления с образцом.
- Окружение — неизменяемый Map; новый вызов получает новое окружение.
- Замыкание хранит параметры, тело и среду определения.
- Рекурсивное замыкание хранит описания группы функций, без ref.
- Список результатов нужен для нескольких вариантов choose.
- Повторный ключ сохраняет выбор; новый ключ задаёт независимое событие.
- observe исключает ветви, а Engine нормирует оставшиеся вероятности.
- delay не кеширует результат; файлы обрабатывает только CLI.

## Ограничения

Реализация рассчитана на небольшие учебные программы. Нет оптимизации
хвостовых вызовов; глубина вычисления ограничена. Перебор вариантов может
расти экспоненциально. Эти ограничения стоит объяснить вместе с устройством eval.
