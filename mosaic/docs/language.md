# Руководство языка

## Лексика и формы

Файл `.mos` содержит ровно одно выражение. Комментарий начинается с `;` и
заканчивается переводом строки. Пробельные символы разделяют токены. Имена
чувствительны к регистру; используются любые непробельные символы, кроме
скобок, кавычек и `;`. Целые числа и зарезервированные слова не могут быть
именами привязок. Операторы `+`, `<=`, `empty?` — обычные имена функций.

```ebnf
expression = integer | string | "true" | "false" | identifier
           | "[", { expression }, "]"
           | "(", expression, expression, { expression }, ")"
           | "(", "fn", "[", identifier, { identifier }, "]", expression, ")"
           | "(", "let", "[", { identifier, expression }, "]", expression, ")"
           | "(", "letrec", "[", { identifier, lambda }, "]", expression, ")"
           | "(", "if", expression, expression, expression, ")"
           | "(", "delay", expression, ")"
           | "(", "force", expression, ")"
           | "(", "observe", expression, expression, ")" ;
lambda = "(", "fn", "[", identifier, { identifier }, "]", expression, ")" ;
integer = [ "+" | "-" ], digit, { digit } ;
```

Специальные формы распознаются раньше общего применения. `(x)` не является
группировкой: вызову нужен хотя бы один аргумент. Литералы дробей не вводятся:
используйте `(/ 1 3)`. Строки поддерживают `\n`, `\r`, `\t`, `\"`, `\\` и
обычные Unicode-символы; `\uXXXX` как escape в исходниках не поддерживается.
В JSON-представлении строк сериализатор может использовать Unicode escapes.

## Данные

Числа — нормализованные рациональные дроби с bigint-числителем и знаменателем.
`(/ 4 2)` даёт `2`, а `(/ 1 3)` остаётся точной дробью. `true` и `false`
отличаются от чисел. Списки могут быть неоднородными и содержать функции и
задержки; однако окончательный результат программы, равенство и варианты
выбора принимают только наблюдаемые данные: числа, логические значения,
строки и конечные вложенные списки таких данных.

## Привязки и замыкания

```lisp
(let [x 10
      add-x (fn [y] (+ x y))]
  (let [x 100] (add-x 2)))
```

Результат `12`: замыкание хранит лексическое окружение определения. Привязки
одного `let` вычисляются слева направо и видят предыдущие привязки. Повтор
имени в одной группе запрещён; вложенное затенение разрешено. Присваивания нет.

`letrec` принимает только лямбды, видимые друг другу:

```lisp
(letrec [even (fn [n] (if (= n 0) true (odd (- n 1))))
         odd  (fn [n] (if (= n 0) false (even (- n 1))))]
  (even 20))
```

Функции принимают один или несколько параметров. Недостаток аргументов
создаёт частично применённую функцию; избыток применяется к результату.
Например, `((fn [x] (fn [y] (+ x y))) 20 22)` даёт `42`.

## Порядок вычисления и ленивость

Язык строгий: сначала вычисляется функция, затем все аргументы слева направо.
Списки также строгие. `if` требует Boolean и вычисляет только выбранную ветвь.
`delay` сохраняет выражение и окружение, `force` вычисляет его. Это
**call-by-name без кеширования**, а не call-by-need.

```lisp
(let [unused (delay (/ 1 0))] 42)
```

Возвращает `42`. Функциональный поток представлен парой `[head delayed-tail]`:

```lisp
(letrec [naturals (fn [n] [n (delay (naturals (+ n 1)))])]
  (stream-take 5 (naturals 0)))
```

`stream-take 1` не форсирует хвост. Повторное `force` повторяет вычисление;
корреляция внутри него обеспечивается ключами `choose`, а не кешем задержки.

## Миры и наблюдения

```lisp
(choose "weather" [[3 "sun"] [1 "rain"]])
```

`choose` — каррируемая функция двух аргументов. Первый — непустая строка-ключ,
второй — непустое распределение из пар `[вес значение]`. Веса должны быть
неотрицательными числами с положительной суммой. Они нормируются; одинаковые
значения объединяются, нулевые веса исключаются. Списки альтернатив вычисляются
строго: нулевой вес не защищает выражение значения от ошибки вычисления.

Первый вызов с ключом разветвляет мир. Повторный возвращает уже выбранное
значение без изменения веса. Перестановка вариантов и пропорциональное
масштабирование весов допустимы. Другое распределение при том же ключе —
ошибка `E_KEY`. Область ключей — весь отдельный мир, не лексический блок.

`(observe condition body)` проверяет Boolean. Ложь отбрасывает этот мир,
истина вычисляет `body`. Нормализация происходит один раз после вычисления
всех выживших миров. Если ни одного не осталось — `E_IMPOSSIBLE`.

## Стандартная библиотека

Все аргументы ниже передаются позиционно. Функции каррируются.

| Функции | Сигнатура / смысл |
|---|---|
| `+ - * /` | Number → Number → Number, деление точное |
| `mod` | Integer → Integer → Integer, остаток со знаком делимого |
| `< <= > >=` | Number → Number → Boolean |
| `=` | Data → Data → Boolean, структурное равенство |
| `not` | Boolean → Boolean |
| `cons` | Value → List → List |
| `head`, `tail` | первый элемент / хвост; пустой список — ошибка |
| `empty?`, `length` | List → Boolean / Integer |
| `append` | List → List → List |
| `text-append` | Text → Text → Text |
| `show` | Data → Text, печатное представление |
| `choose` | Text → List [Number Data] → Data в каждом мире |
| `read-text` | Text → Text, чтение заранее переданного входа |
| `write-text` | Text → Text → Text, добавление логического артефакта |
| `identity` | a → a |
| `compose` | (b → c) → (a → b) → a → c |
| `map` | (a → b) → List a → List b |
| `filter` | (a → Boolean) → List a → List a |
| `foldl` | (a → b → a) → a → List b → a |
| `reverse` | List a → List a |
| `range` | Number → Number → List Number, шаг 1, верхняя граница исключена |
| `sum`, `product` | List Number → Number, для пустого списка 0 и 1 |
| `take` | Number → List a → List a, при n ≤ 0 пустой список |
| `all`, `any` | (a → Boolean) → List a → Boolean, короткое замыкание |
| `zip` | List a → List b → List [a b], до конца короткого списка |
| `iterate` | (a → a) → a → Stream a |
| `stream-take` | Number → Stream a → List a |

Prelude динамически типизирован. Для `range`, `take` и `stream-take`
предполагаются целочисленные границы/счётчики; дроби не запрещены отдельной
проверкой, поведение следует сравнению и уменьшению/увеличению на 1.
В языке нет нативного `and`/`or`; для ленивой логики используйте `if`.
