# API стандартной библиотеки

[Главная](index.md) · [Синтаксис](syntax.md) · [Примеры](examples.md) · [Архитектура](architecture.md)

В таблицах указано число аргументов. Все функции допускают частичное применение.
Базовые операции реализованы в `Primitives.fs`, функции высшего порядка —
на самом Mosaic в `Prelude.fs`.

## Арифметика

| Функция | Аргументы | Результат |
|---|---|---|
| `+`, `-`, `*`, `/` | два числа | сумма, разность, произведение, точное частное |
| `mod` | два целых числа | остаток, знак совпадает со знаком делимого |

```lisp
[(+ 2 3) (- 10 4) (* 6 7) (/ 1 3) (mod 17 5)]
```

Результат: `[5 6 42 1/3 2]`. Числа имеют произвольную точность.
Деление и остаток по нулю дают `E_ZERO`.

## Сравнения

| Функция | Аргументы | Результат |
|---|---|---|
| `=` | два значения данных | структурное равенство |
| `<`, `<=`, `>`, `>=` | два числа | Boolean |
| `not` | один Boolean | логическое отрицание |

```lisp
[(= [1 2] [1 2]) (< (/ 2 3) (/ 3 4)) (not false)]
```

Результат: `[true true true]`. Функции и отложенные выражения на равенство
не сравниваются. Значения разных типов, например `1` и `true`, не равны.

## Базовые операции со списками

| Функция | Аргументы | Результат |
|---|---|---|
| `cons` | элемент, список | новый список с элементом в начале |
| `head` | список | первый элемент |
| `tail` | список | список без первого элемента |
| `empty?` | список | проверка на пустоту |
| `length` | список | число элементов |
| `append` | два списка | соединённый список |

```lisp
[(cons 0 [1 2]) (head [4 5]) (tail [4 5])
 (empty? []) (length [4 5]) (append [1] [2 3])]
```

Результат: `[[0 1 2] 4 [5] true 2 [1 2 3]]`.
`head` и `tail` для пустого списка возвращают ошибку `E_EMPTY`.

## Функции высшего порядка

| Функция | Аргументы | Назначение |
|---|---|---|
| `map` | функция, список | преобразовать каждый элемент |
| `filter` | предикат, список | оставить подходящие элементы |
| `foldl` | функция, начальное значение, список | свёртка слева |
| `identity` | значение | вернуть его без изменения |
| `compose` | f, g, x | вычислить f(g(x)) |
| `all`, `any` | предикат, список | все / хотя бы один элемент удовлетворяют условию |

```lisp
(let [squares (map (fn [x] (* x x)) [1 2 3 4])]
  (foldl + 0 (filter (fn [x] (> x 5)) squares)))
```

Результат: `25`. На пустом списке `all` возвращает `true`, `any` — `false`.
Эти функции прекращают проверку, когда ответ уже известен.

## Удобные функции для списков и потоков

| Функция | Аргументы | Назначение |
|---|---|---|
| `range` | начало, конец | последовательность с шагом 1, конец не включён |
| `take` | количество, список | первые элементы |
| `reverse` | список | обратный порядок |
| `sum`, `product` | список чисел | сумма / произведение; для пустого списка 0 / 1 |
| `zip` | два списка | пары элементов до конца более короткого списка |
| `iterate` | функция, начальное значение | бесконечный ленивый поток |
| `stream-take` | количество, поток | конечный список первых элементов |

```lisp
[(range 2 6) (take 2 [7 8 9]) (sum []) (product [])
 (zip [1 2] [3]) (stream-take 4 (iterate (* 2) 1))]
```

Результат: `[[2 3 4 5] [7 8] 0 1 [[1 3]] [1 2 4 8]]`.
Для `range`, `take` и `stream-take` предполагаются целые границы/счётчики.
Отдельной проверки целочисленности в Prelude нет: дробные аргументы будут
обрабатываться теми же сравнениями и прибавлением или вычитанием единицы.
`stream-take 1` не форсирует хвост, а при количестве ≤ 0 возвращается `[]`.

## Выборы

`(choose name alternatives)` возвращает значение в каждом возможном сценарии.
Имя — строка; варианты — список пар `[вес значение]`.

```lisp
(choose "coin" [[1 "heads"] [1 "tails"]])
```

Результат: `"heads" @ 1/2`, `"tails" @ 1/2`. Повторный ключ сохраняет
предыдущий выбор. Для отбора сценариев используется специальная форма
`observe`, описанная в [синтаксисе](syntax.md).

## Строки и файловый ввод-вывод

| Функция | Аргументы | Результат |
|---|---|---|
| `text-append` | две строки | соединение строк |
| `show` | значение данных | его текстовое представление |
| `read-text` | имя входа | текст, переданный через `--input` |
| `write-text` | имя выхода, текст | записанный логический текст; возвращает тот же текст |

```lisp
(text-append "sum = " (show (sum [1 2 3])))
```

Результат: `"sum = 6"`. Файловые операции показаны в `examples/files.mos`.
Они не открывают файлы внутри интерпретатора: CLI читает входы до вычисления
и записывает запрошенные выходы после него. Повторная запись разного текста
под одним именем в сценарии запрещена. Экспорт возможен, только если все
выжившие сценарии содержат одинаковый текст по указанному имени.
