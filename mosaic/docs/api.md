# Встроенные функции и стандартная библиотека

[Документация](index.md) · [Синтаксис](syntax.md) · [Примеры](examples.md)

Все функции поддерживают частичное применение. Аргументы перечислены в порядке
передачи: например, `(map f xs)` и `(pipe xs (map f))` дают одинаковый результат.

## Встроенные операции

Операции этого раздела реализованы в `Primitives.fs`.

| Вызов | Результат |
|---|---|
| `(+ a b)`, `(- a b)`, `(* a b)` | Сумма, разность, произведение целых чисел |
| `(/ a b)` | Целочисленное деление с округлением к нулю |
| `(mod a b)` | Остаток от деления, знак совпадает со знаком `a` |
| `(= a b)` | Структурное равенство данных, включая вложенные списки |
| `(< a b)`, `(<= a b)`, `(> a b)`, `(>= a b)` | Сравнение целых чисел |
| `(not value)` | Отрицание логического значения |
| `(cons x xs)` | Новый список с `x` в начале |
| `(head xs)` | Первый элемент; ошибка для пустого списка |
| `(tail xs)` | Все элементы после первого; ошибка для пустого списка |
| `(empty? xs)` | Проверка пустоты списка |
| `(length xs)` | Число элементов |
| `(append xs ys)` | Объединение двух списков |
| `(text-append a b)` | Объединение строк |
| `(show value)` | Текстовое представление данных |
| `(read-text name)` | Содержимое именованного текстового входа |
| `(write-text name text)` | Подготовка текстового выхода; возвращает `text` |

`/` и `mod` сообщают об ошибке при делителе `0`. Равенство не сравнивает
функции и отложенные выражения. Вызов `show` для строки включает кавычки
в результат: это представление значения, а не удаление кавычек.

```lisp
[(+ 2 3) (/ 7 3) (mod 7 3) (cons 1 [2 3]) (show [1 2])]
```

Результат: `[5 2 1 [1 2 3] "[1 2]"]`.

## Списки и функции высшего порядка

Эти функции определены на Mosaic в `Prelude.fs` и доступны в каждой программе.

| Вызов | Результат |
|---|---|
| `(identity x)` | `x` без изменений |
| `(compose f g x)` | `f`, применённая к результату `g x` |
| `(map f xs)` | Результаты применения `f` к каждому элементу |
| `(filter predicate xs)` | Элементы, для которых предикат вернул `true` |
| `(foldl f initial xs)` | Свёртка слева направо: `f` получает аккумулятор и элемент |
| `(reverse xs)` | Элементы в обратном порядке |
| `(range start stop)` | Целые от `start` включительно до `stop` исключительно, шаг 1 |
| `(sum xs)`, `(product xs)` | Сумма и произведение; для пустого списка — `0` и `1` |
| `(take n xs)` | Не более первых `n` элементов; при `n <= 0` — пустой список |
| `(all predicate xs)` | Все элементы удовлетворяют предикату; для пустого — `true` |
| `(any predicate xs)` | Хотя бы один элемент удовлетворяет предикату; для пустого — `false` |
| `(zip xs ys)` | Список пар до конца более короткого списка |

`range` возвращает пустой список, если `start >= stop`. `all` и `any`
прекращают проверку, когда результат уже определён.

```lisp
(pipe (range 1 6)
  (map (fn [x] (* x x)))
  (foldl + 0))
```

Результат: `55`.

## Ленивые потоки

| Вызов | Результат |
|---|---|
| `(iterate step seed)` | Поток `seed`, `step seed`, `step (step seed)` и т. д. |
| `(stream-take n stream)` | Обычный список первых `n` элементов потока |

Поток — список из двух элементов: текущее значение и отложенный хвост.
`stream-take` не вычисляет хвост после последнего запрошенного элемента.
Если `n <= 0`, возвращается пустой список.

```lisp
(stream-take 6 (iterate (* 2) 1))
```

Результат: `[1 2 4 8 16 32]`.

## Ввод-вывод и CLI

```sh
./mosaic FILE [--input NAME PATH] [--output NAME PATH]
```

Опции можно повторять с разными именами. Имена входов должны быть уникальны;
у выходов должны быть уникальны и имена, и полные пути. Каталог назначения
нужно создать заранее. `./mosaic --help` выводит справку, `run FILE` также
допускается вместо `FILE`.

`read-text` обращается к переданному CLI тексту. `write-text` добавляет текст
в неизменяемую таблицу выходов, реальная запись происходит в CLI. Повторный
выход с тем же именем и тем же текстом допустим; с другим текстом — ошибка.
Без `--output` подготовленный текст остаётся только в результате вычисления.

При ошибке вычисления или отсутствии запрошенного выхода запись не начинается.
После проверки всех имён CLI записывает файлы по очереди. Ошибка самой файловой
системы не откатывает уже записанные файлы.

CLI печатает значение программы в stdout, ошибки — в stderr. Код завершения
`0` означает успех, `1` — ошибку программы или файлов, `2` — ошибку аргументов.
Служебные ошибки CLI: `E_USAGE`, `E_IO`, `E_EXPORT`.
