## Зависимость от состава команды

В найденном задании для двух человек достаточно интерпретатора, примеров
и README. Для трёх требуется более подробная документация на GitHub Pages.
Для большей команды перечислены возможные расширения: браузерная IDE,
Jupyter, трансляция в JS, расширение VS Code; они не реализованы здесь.
Пользователь подтвердил **индивидуальное выполнение**. Проект покрывает
основной набор функциональности и снабжён расширенной документацией;
командные расширения не включены в обязательный объём этой работы.

Полная документация подготовлена независимо от размера команды. Для Pages
есть конфигурация Jekyll и ручной workflow `.github/workflows/docs.yml`.
Это готовность к публикации, а не утверждение, что Pages уже включён.
В Settings → Pages репозитория нужно выбрать GitHub Actions, затем запустить
workflow **Publish Mosaic documentation** на нужной ветке. Доступность Pages
для приватного репозитория зависит от тарифа GitHub.

## Перед сдачей

1. Подтвердить у преподавателя актуальность восстановленного задания и место
   сдачи после закрытия Classroom.
2. Заполнить ФИО, группу и фактический вклад участников.
3. При желании опубликовать подготовленные Pages как дополнение к индивидуальному проекту.
4. Прочитать семантику и самостоятельно разобрать примеры из defense.md.

Этапы разработки сохранены отдельными коммитами в истории Git.
