# Документация Mosaic

Mosaic — небольшой функциональный язык для обработки списков.
Интерпретатор реализован на F#, стандартная библиотека — на самом Mosaic.

```lisp
(pipe [1 2 3 4]
  (map (* 2))
  sum)
```

Результат: `20`. Через `pipe` список передаётся в `map`, затем результат — в `sum`.
