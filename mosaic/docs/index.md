# Mosaic

Функциональный язык на F# с рекурсией, замыканиями, списками и именованными
вероятностными выборами. Проект состоит из парсера, рекурсивного интерпретатора,
небольшой библиотеки, примеров и тестов.

## Быстрый старт

Из папки `mosaic/`, при установленном .NET SDK 10:

```sh
./mosaic examples/factorial.mos
./mosaic examples/shared-weather.mos --explain
```

## Возможности

- Неизменяемые значения и лексические замыкания.
- Рекурсия и функции высшего порядка.
- Списки и отложенные вычисления.
- Точные дроби, выборы и отбор сценариев по условию.
- Чтение и запись текстовых файлов через командную строку.
