# Синтаксис Mosaic

[Документация](index.md) · [API](api.md) · [Примеры](examples.md)

## Значения и вызовы

Файл содержит одно выражение. Числа — целые произвольной точности. Логические
значения записываются как `true` и `false`, строки — в двойных кавычках,
списки — в квадратных скобках. Списки могут содержать значения разных типов.

```lisp
[42 -7 true "hello" [1 2 3]]
```

В строках поддерживаются `\n`, `\r`, `\t`, `\"`, `\\`.
Комментарий от `;` продолжается до конца строки.

Вызов функции имеет вид `(function argument ...)`:

```lisp
(+ 2 (* 3 4))
```

Результат: `14`. Приоритеты операторов не нужны: порядок задаётся скобками.
Функция и аргументы вычисляются слева направо. Все арифметические операции
принимают два аргумента; `/` отбрасывает дробную часть в сторону нуля,
`mod` возвращает остаток со знаком делимого.

## Привязки let

```lisp
(let [x 4
      y (+ x 1)]
  (* x y))
```

Результат: `20`. Привязки последовательные: `y` видит `x`. Изменить значение
привязки нельзя, но во вложенном `let` можно использовать то же имя.
Повторять имя внутри одного списка привязок нельзя. Пустой список допустим.

## Функции и замыкания

Форма `(fn [parameters] body)` создаёт функцию. Параметров должен быть хотя бы
один, их имена не должны повторяться. Замыкание сохраняет окружение определения:

```lisp
(let [x 10
      add-x (fn [y] (+ x y))]
  (let [x 99]
    (add-x 2)))
```

Результат: `12`. Позднее затенение `x` не меняет окружение `add-x`.

Если аргументов не хватает, возвращается функция с оставшимися параметрами.
Лишние аргументы применяются к результату вызова, если он тоже функция.
Например, `((fn [x] (fn [y] (+ x y))) 2 3)` равно `5`.
Вызовы без аргументов не поддерживаются.

Функции можно передавать и хранить в списках, но нельзя сравнивать через `=`
или печатать как окончательный результат программы.

## Рекурсия letrec

В `letrec` разрешены только определения через `fn`. Все функции группы видят
друг друга и сами себя:

```lisp
(letrec [even (fn [n] (if (= n 0) true (odd (- n 1))))
         odd  (fn [n] (if (= n 0) false (even (- n 1))))]
  [(even 10) (odd 11)])
```

Результат: `[true true]`.

## Условие if

`(if condition yes no)` требует логическое условие. Вычисляется только
выбранная ветвь:

```lisp
(if true 42 (/ 1 0))
```

Результат: `42`. В Mosaic число `0` не заменяет `false`.

## Цепочки pipe

Форма `(pipe initial step ...)` вычисляет начальное выражение, затем по очереди
вычисляет каждый шаг и вызывает его с текущим результатом как единственным
аргументом. Шаг — функция или выражение, возвращающее функцию.

```lisp
(pipe 3
  (+ 1)
  (* 2))
```

Результат: `8`: сначала `3 + 1`, затем `4 * 2`. В `(pipe xs (map f) sum)`
выражение `(map f)` уже содержит первый аргумент; `xs` становится вторым.
`(pipe value)` без шагов возвращает само значение.

Начальное выражение и каждый пройденный шаг вычисляются один раз. При ошибке
следующие шаги не выполняются. Шаги используют обычное лексическое окружение;
скрытой переменной для текущего результата нет. Значение может менять тип
между шагами: список → число → строка.

## Отложенные вычисления

`(delay expression)` сохраняет выражение вместе с окружением, а `(force value)`
вычисляет его. При каждом `force` вычисление повторяется, кеширования нет.

```lisp
(let [x 3
      pending (delay (+ x 1))]
  (let [x 100]
    (force pending)))
```

Результат: `4`. Отложенное значение нельзя печатать без `force`.
Поток представлен парой `[head (delay tail)]`; библиотечный `stream-take`
вычисляет только нужное число элементов.

## Ошибки

Типы проверяются во время выполнения. Сообщение содержит имя файла, строку,
столбец и код, например: `program.mos:2:8: E_NAME: Unknown name 'missing'`.

| Код | Причина |
|---|---|
| `E_NAME` | Имя отсутствует в окружении |
| `E_TYPE` | Неподходящие типы аргументов или условия |
| `E_CALL` | Вызов значения, которое не является функцией |
| `E_ZERO` | Деление или остаток от деления на ноль |
| `E_EMPTY` | `head` или `tail` пустого списка |
| `E_FORCE`, `E_RESULT` | Неподходящее отложенное или итоговое значение |
| `E_BINDING`, `E_FN`, `E_LETREC`, `E_FORM` | Неправильная специальная форма |
| `E_EOF`, `E_DELIMITER`, `E_TRAILING` | Незакрытые скобки или лишнее выражение |
| `E_STRING`, `E_ESCAPE` | Ошибка в строке |
| `E_DEPTH`, `E_RECURSION` | Превышение допустимой вложенности |
| `E_INPUT`, `E_OUTPUT` | Отсутствующий вход или конфликт текстовых выходов |

Вложенность исходного текста и вычисления ограничена 256 уровнями.
