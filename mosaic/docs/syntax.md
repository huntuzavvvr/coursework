# Синтаксис Mosaic

[Главная](index.md) · [API](api.md) · [Примеры](examples.md) · [Архитектура](architecture.md)

## Лексические элементы

Вызов функции имеет вид `(имя аргументы)`. Элементы списка записываются в
квадратных скобках и разделяются пробелами. В файле должно быть одно выражение.
Комментарий начинается с `;` и продолжается до конца строки.

| Значение | Запись |
|---|---|
| Целое число | `42`, `-10` |
| Точная дробь | `(/ 1 3)` — выражение деления |
| Boolean | `true`, `false` |
| Строка | `"hello"` |
| Список | `[1 2 3]`, `[]` |

В строках поддерживаются `\n`, `\r`, `\t`, `\"` и `\\`. Unicode-символы
можно писать непосредственно. Имена чувствительны к регистру; скобки,
кавычки, пробелы и `;` разделяют токены. Числа и ключевые слова нельзя
использовать как имена привязок. `+`, `<=` и `empty?` — имена обычных функций.

## Привязки let

```lisp
(let [x 10
      y (+ x 5)]
  (* x y))
```

Результат: `150`. Привязки вычисляются слева направо, поэтому `y` видит `x`.
Повтор имени внутри одной группы запрещён, вложенное затенение разрешено.
Изменить уже созданное значение нельзя.

## Функции и замыкания

```lisp
(let [make-adder (fn [x] (fn [y] (+ x y)))
      add5 (make-adder 5)]
  (add5 10))
```

Результат: `15`. Функция сохраняет окружение, в котором была определена.
Можно объявлять несколько параметров и передавать их по частям:

```lisp
(let [add (fn [a b] (+ a b))
      add5 (add 5)]
  (add5 10))
```

Недостающие аргументы образуют новую функцию. Избыточные аргументы
применяются к результату предыдущего вызова. Функциям нужен хотя бы один
параметр; `(f)` не является вызовом без аргументов или группировкой.

## Рекурсия

```lisp
(letrec [fact (fn [n]
               (if (= n 0) 1 (* n (fact (- n 1)))))]
  (fact 6))
```

Результат: `720`. `letrec` принимает только определения функций. Функции
одной группы видят друг друга, поэтому можно записывать взаимную рекурсию.

## Условные выражения

```lisp
(let [x 7]
  (if (< x 10) "small" "large"))
```

Вычисляется только выбранная ветвь. Условие должно быть Boolean; число `1`
не заменяет `true`. Для короткого замыкания логики используется вложенный `if`.

## Списки

```lisp
(let [numbers [1 2 3]]
  [(head numbers) (tail numbers) (cons 0 numbers)])
```

Результат: `[1 [2 3] [0 1 2 3]]`. Элементы вычисляются строго слева направо.
Список может содержать разные типы, в том числе функции и задержки.

## Ленивые вычисления

```lisp
(let [unused (delay (/ 1 0))]
  (force (delay 42)))
```

Результат: `42`. `delay` сохраняет выражение и окружение, а `force` запускает
вычисление. Результат не кешируется: повторный `force` вычисляет тело повторно.
Это явная ленивость по имени, а не ленивость всего языка.

Поток представлен списком `[голова отложенный-хвост]`. Библиотека содержит
`iterate` и `stream-take` для работы с такими последовательностями.

## Именованные выборы и observe

```lisp
(let [a (choose "a" [[1 0] [1 1]])
      b (choose "b" [[1 0] [1 1]])]
  (observe (> (+ a b) 0) a))
```

После исключения пары `[0 0]` результат равен `0 @ 1/3`, `1 @ 2/3`.
Вероятность выполнения условия, `evidence`, равна `3/4`.

Аргументы `choose` — непустое имя и список пар `[вес значение]`. Веса должны
быть неотрицательными, их сумма — положительной. Веса нормируются. Одинаковые
значения объединяются, нулевые веса исключаются. Сами выражения вариантов
вычисляются строго, даже если их вес равен нулю.

Повторный ключ означает прежнее событие и не умножает вероятность второй раз.
Другой порядок или пропорционально увеличенные веса допустимы; действительно
другое распределение при том же ключе вызывает `E_KEY`. Имена событий общие
для всего сценария, независимо от лексической области.

`observe` с ложным условием отбрасывает сценарий и не вычисляет тело. Если
отброшены все сценарии, возвращается `E_IMPOSSIBLE`.

## Типы и ошибки

Типы проверяются во время вычисления. Например, `(+ 1 true)` даёт `E_TYPE`,
а `(head [])` — `E_EMPTY`. Окончательный результат и варианты выбора должны
быть данными: числами, строками, Boolean или конечными списками таких значений.
Функцию перед выводом нужно применить, отложенное выражение — форсировать.

Полный список библиотечных функций — в [API](api.md).
