# Статус проекта Mosaic

## Реализовано

| Требование | Реализация |
|---|---|
| Функциональный язык | F#, неизменяемые Map/list, рекурсивный eval |
| AST и парсер | Syntax.fs и Reader.fs, позиции синтаксических ошибок |
| Именованные переменные | let, последовательные привязки, затенение |
| Рекурсия | letrec, в том числе взаимная |
| Функции и замыкания | fn, лексическая область видимости, частичное применение |
| Ленивое вычисление | delay/force без кеширования, поток Фибоначчи |
| Списки и библиотека | map, filter, foldl и другие функции |
| Файловый ввод-вывод | read-text/write-text, пути через CLI |
| Факториал и другие примеры | семь файлов в examples/ |
| Собственная особенность | именованные выборы и observe, точные вероятности |
| Документация | README, синтаксис, API, примеры и архитектура |
| Использование ИИ | AI_USAGE.md и материалы в ai/ |

## Проверки

Команда из папки проекта: `./scripts/verify.sh`.

- Release-сборка без ошибок и предупреждений.
- 71 проверка семантики на F#.
- Семь запускаемых примеров и проверки CLI, ошибок и файлового вывода.

## Ограничения

Нет оптимизации хвостовой рекурсии, статической типизации и компилятора.
Глубина вычисления — до 256 уровней, промежуточный список сценариев — до 1024.
Это ограничения учебной реализации, а не свойства математической модели языка.
