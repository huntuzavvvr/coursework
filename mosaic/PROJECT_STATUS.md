# Статус проекта Mosaic

## Реализовано

| Возможность | Реализация |
|---|---|
| Функциональное ядро | F#, неизменяемые Map/list, рекурсивный eval |
| AST и парсер | Syntax.fs и Reader.fs, позиции ошибок |
| Именованные значения | let, последовательные привязки, затенение |
| Рекурсия | letrec, в том числе взаимная |
| Функции и замыкания | fn, лексическая область видимости, частичное применение |
| Цепочки преобразований | pipe, обычные функции в качестве шагов |
| Ленивые вычисления | delay/force, поток Фибоначчи |
| Списки и библиотека | map, filter, foldl и другие функции на Mosaic |
| Файловый ввод-вывод | read-text/write-text, пути через CLI |
| Примеры | семь программ, включая факториал |
| Документация | README, синтаксис, API, примеры и архитектура |
| Использование ИИ | AI_USAGE.md и записи этапов в ai/ |

## Проверки

Команда из папки проекта: `./scripts/verify.sh`.

- Release-сборка без ошибок и предупреждений.
- 70 проверок семантики на F#.
- Семь примеров, проверки CLI, диагностик и файлового вывода.

## Ограничения

Нет статического вывода типов, дробных чисел, компилятора и оптимизации
хвостовых вызовов. Глубина разбора и вычисления ограничена 256 уровнями.
Ленивые выражения вычисляются повторно при каждом `force`.
