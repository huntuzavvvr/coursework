# Использование генеративного ИИ

Проект подготовлен 17 сентября 2026 с помощью **OpenAI Codex** в приложении
Codex. ИИ участвовал в выборе идеи, проектировании, написании всех модулей,
документации, примеров и тестов, а также в запуске сборок и исправлении ошибок.
Этот документ не утверждает, что студент вручную написал сгенерированный код.

## Предоставленный контекст

Пользователь попросил создать самостоятельный функциональный язык с полноценной
реализацией и оформлением, указал репозиторий `coursework` и предоставил пример
`funcpro-coursework-swag`. Из README примера восстановлен текст задания. Читались
README, статус, файл проекта и документация примера; его реализации AST,
парсера и интерпретатора не копировались и не использовались как заготовки.

Ссылка на GitHub оказалась сообщением о закрытии Classroom, а не заданием.
Принадлежность к курсу и дополнительные требования преподавателя по ней
установить невозможно. В ходе работы пользователь подтвердил, что выполняет
курсовую индивидуально.

## Проверка результата

Проверки включают независимые ожидаемые ответы для примеров, контрпримеры к
неверным вероятностным трактовкам, ошибки, глубокую рекурсию, файловый I/O и
контроль отсутствия мутации в ядре. Численные ответы в демонстрациях
сопоставлены с ручными вычислениями (см. docs/examples.md).

Тесты не заменяют понимания проекта. Перед защитой необходимо разобрать
код машины, области видимости, корреляцию, нормализацию и границу I/O,
внести собственные доработки и заполнить реальные сведения об участниках.
